Read-only views of mlegls-pi's records store: notes logs (global and per repository) and lives.

The page lists each notes log and each life. Selecting one shows what an agent wakes to: the notes cover in its line budget, or the life's shared view. Clicking a block opens the blocks under it, down to single notes or whole messages. A notes log can also be listed note by note.

The plugin runs `read.ts` from an mlegls-pi checkout with bun, so it needs that checkout and bun on this machine (see its settings).
