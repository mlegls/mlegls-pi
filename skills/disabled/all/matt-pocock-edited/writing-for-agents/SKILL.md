Reference for any document an agent consumes — a skill, an `AGENTS.md`/`CLAUDE.md`, a pointed-at doc. The same levers make each one predictable. For skill frontmatter, invocation choice, and router skills, read [`SKILL-MECHANICS.md`](SKILL-MECHANICS.md).

- **Context pointer**: a line in context naming out-of-context material and the condition for reaching it (a skill description, an `AGENTS.md` line). The *wording* decides whether the agent reaches the material: a must-have target behind a weak pointer is a variance bug — sharpen the wording before inlining. Front-load the leading word; one trigger per genuinely distinct branch (synonyms are one branch written twice); cut identity the body already carries.
- **The two loads**: always-loaded material spends **context load** (tokens and attention every turn); documents with no pointer ride on **cognitive load** (the human is the index — the price of human agency, spent where judgement matters).
- **Information hierarchy**: in-file steps → in-file reference → disclosed reference behind a pointer. **Progressive disclosure** protects the top: inline what every branch needs, disclose what only some branches reach. **Co-locate** a concept's definition, rules, and caveats under one heading — scattering fragments one meaning across many places (distinct from duplication, which repeats it). **Sprawl** — too long even with every line live — is cured by disclosure and by splitting per branch/sequence.
- **Completion criteria**: every step ends on one. Two levers: **clarity** (a vague bound like "understanding reached" invites premature completion — sharpen the bound first; hide later steps only across a real context boundary) and **demand** ("every modified model accounted for" forces legwork where "produce a change list" does not; "every rule applied" binds flat reference the same way).
- **Split** only when it pays: by sequence when visible later steps tempt rushing the current one; by invocation per `SKILL-MECHANICS.md`.
- **Leading words**: a compact pretrained concept the agent thinks with (_fog of war_, _tracer bullets_), repeated as a token so it anchors behaviour in the body and triggers invocation in a pointer. A coined word recruits no priors — reach for an existing one. Hunt for passages begging to collapse: "fast, deterministic, low-overhead" → _tight_; "a loop you believe in" → _red_.
- **Negation** drags the forbidden behaviour into context and makes it *more* available. State the positive target ("write one-line comments"); a prohibition earns its place only as a hard guardrail you can't phrase positively, paired with the positive.
- **Pruning**: single source of truth per meaning. The environment (`package.json` scripts, config, `--help`) is a source of truth too — a document restating it is a **cache**, worthwhile only for expensive lookups (unwritten conventions, reasons, gotchas), never one-command facts that go stale. Without pruning the default fate is **sediment**. Hunt **no-ops**: an instruction the model already obeys by default; the test is model-relative — settle disputes by running the document. It grades leading words too: a word too weak to beat the default (_be thorough_) needs a stronger word (_relentless_), not a different technique.
