Reconstruct the thread from its durable traces: issues and PRs via `gh-axi`,
agent sessions, communication, docs, and the current code. With no named topic,
look for recent work and what is still pending.

Separate what happened, what was decided, and what was merely proposed. Return
the useful orientation and source pointers, including the next unresolved move.
