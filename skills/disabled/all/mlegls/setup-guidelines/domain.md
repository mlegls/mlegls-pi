# Domain docs

`docs/README.md` maps roles, contexts, and paths. Read the mapped stories and
architecture documents relevant to the work; descend into local docs and code
as the question narrows. A mapped path can be absent until its first write.

The glossary is shared language for code, issues, hypotheses, and tests. A
missing or misleading term is an architectural question, not just a synonym
to invent locally. Decisions can be reopened; make the disagreement visible:

> Contradicts ADR-0007 (event-sourced orders), but worth reopening because…

`architecture` describes document roles and upkeep. `/setup-guidelines`
establishes a missing or incomplete map.
