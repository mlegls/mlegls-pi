2. **Global contracts.** Instantiate exactly one getTracker(target, {inflight:false}) per run. Global snapshot is uncached and fail-closed with the existing fix-and-auto-retry diagnostic. Replace every branch/path snapshot call, HEAD cache, ticketText branch fallback, driveNone file regex and conflict `git show` issue fallback. Use Tracker.text/fields at actual prompt preparation time. Display identities without requiring Issue.file. 3. **Scheduling.** At each tick, recover proven landings and target closes, observe/recover refinement ownership, and retry pending landed-operation retirement before walking. Derive a fresh context for each destination: exact into, ledger, recorded active/adopting tokens and unaccepted owned identities. Visit active refine chains before their newly created children. Use `schedulingView` for child selection, parking, why/holds, join readiness and root finishing; locally satisfied children disappear from remaining work, while canonical stages stay open. A node's @self starts from its collector only after all remaining children are locally satisfied. Preserve root delegation, human/deferred/move-out behavior, waiting/checkpoint/provider/relaunch/integrate budgets and exception scopes. Remove catchUp entirely; global rulings need no branch merge. `refreshWorker` still transports collector code into successors before setup.

Pass exact workers/collector cleanup receipts; update the destination test set after success. Save ledger/results before deleting the chain. Iterate landed operations on every tick to retire their recorded resources; mark cleanup done only on successful retirement/deletion, leaving failures replayable. Never merge ledger-landed code twice. Recover prepared-head ancestry under the integrate serialization lock. Call closeAtTarget before deciding finished; pending close errors retry automatically. 5. **Provisional launch.** Persist beginRefinement for the actual worker handle before dispatch, and put its exact `reconcile:<root>/<handle>` claim token in both initial and prepared refine prompts. The current git-lock retry chooses a `-rN` handle: each actual attempt must have its own saved baseline/token, and a failed attempted launch must stop/clean that attempt before another writer starts. 6. **Failure/continuation.** Wire stopWriter to exact registered thread stop and propagate stop failure instead of proceeding under a live writer. Waiting/same-session answers retain the attempt. Owner steering may explicitly adopt a still-provisional live attempt with resolution `{action:"retry", adopt:true}`; add optional `adopt` to Resolution and the `reconcile_resolve` tool schema/description. Do not resurrect already-cleaned children. Redispatch, move-out, parking, leaving the subtree and explicit stop discard any unaccepted attempts after stopping their writers; accepted children remain reserved pending delivery. Move-out additionally releases this run's stable subtree reservation, not foreign claims.
7. **Acceptance/report cursor.** Parse/validate refine handoff children, save its report/ts into the attempt and call acceptRefinement using an ensured collector even for promotion stubs. Re-read the promoted contract before implementation; start from the collector's code with the correct self flag (promotion is not a child join).
