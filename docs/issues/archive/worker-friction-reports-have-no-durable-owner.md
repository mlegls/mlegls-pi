`agents/_common.md` asks workers to include tooling friction in the final report: “the parent consolidates them.” The tracker procedure instead says whoever encounters a friction files an idea immediately and reports its link. September 26 workers repeatedly followed the former path. Subtree lint reads issue bodies, not final reports, so its `unowned` finding cannot catch observations that never reach an issue.

Resolved: the shared worker prompt now requires filing on encounter and linking the issue in the report. Cross-project observations go to the tool's tracker if accessible, otherwise a local issue naming the owner. Existing tracker rules already permit new idea files on a worker branch; no collector or new reporting format was added. Live worker adoption has not been measured.
