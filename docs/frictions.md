# Frictions

- Desktop restoration is now isolated in `extensions/exec/desktop-restore.ts`, with versioned, image-free, allowlisted records and legacy projection. It still targets pi-computer-use 0.5.1’s named-tool-result reconstruction contract: upstream exposes no restoration API on the factory-owned manager. Removing the remaining projection needs versioned `exportRestorationRecords()` / `restoreRestorationRecords(records)` on that same manager, plus branch-reset semantics. Cached-outline discovery similarly remains a local substitute for upstream subrole/unlabeled search; its scope and incompleteness are explicit. Next: simplify upstream.
- Exec’s explicit skill-ownership marker requires the local pi-better-skills dependency commits `f87a642` and `a87cfcc`; stock 1.3.2 heuristically reinterprets exec output. The local patch skips inference/expansion for marked results and corrects raw-read guidance, but must be retained when updating until upstream supports the contract. Next: upstream the boundary.
- REPL cells transpile TypeScript, but imported `.ts` modules still follow Node’s native strip-only loader. Importing `Kernel.ts` failed on a constructor parameter property during dogfooding; loading it through `jiti` worked. Use built JavaScript or `jiti` for such modules. A unified import transformer would remove the mismatch, but requires a broader module-loader decision than the display/skill changes. Next: simplify.
